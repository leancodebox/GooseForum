# GooseForum 主题结构参考原型

本目录保存五个静态论坛主题基准，用于讨论未来主题入口和 SDK 边界，不参与 `resource` 构建，也不是待直接合并的产品实现。

- `02-classic-board.html`：传统分区、统计和最后回复驱动的高密度论坛。
- `03-community-portal.html`：焦点内容、频道矩阵和榜单组成的社区门户。
- `04-qa-workshop.html`：问题状态、回答、票数和标签驱动的问答社区。
- `05-editorial-forum.html`：数字杂志、长内容与编辑精选导向的论坛。
- `06-gallery-community.html`：作品优先、视觉探索与作者表达导向的社区。

打开 `index.html` 可以进入总览。所有页面均为纯静态 HTML/CSS，不调用真实接口。
